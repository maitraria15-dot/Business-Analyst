# Loan Portfolio Risk Analysis - Excel Dashboard
## 01. Project Overview
This project analyse a loan portfolio of 500 loans toataling $834.8M in sanctioned loan amount and $466.5M outstanding balance.
## 02. The objective was to evaluate:
* Portfolio overall health
* Risk COnecentration by Product and Region
* Default distribution across Risk Bands.

The analysis was performed entirely in Microsoft Excel using Pivots and Structured EDA techniques

## 03. Key Insights
* Portfolio is moderately diversified but concentrated in Home Loans (~ 51% exposure)
* Overall default rate stands at 2.6%, with 15% accounts in 30+ DPD.
* Credit stress is more concentrated by Product than risk band.
